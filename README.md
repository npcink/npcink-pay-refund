Refund management for Alipay and WeChat Pay with WordPress admin settings, operator permissions, refund logs, and release packaging.

== Description ==

Magick Refund provides an admin-side refund workflow for Alipay and WeChat Pay. It stores refund records in a custom database table, supports operator permission controls, and keeps payment secrets in a separate non-autoloaded option.

The release package must be generated with `composer build:zip` so the required Composer dependencies are included.

== Installation ==

1. Run `composer build:zip`.
2. Install the generated zip from the `build/` directory in WordPress.
3. Configure Alipay, WeChat Pay, and refund operator permissions from the plugin settings page.

== Frequently Asked Questions ==

= Can I install a raw source archive? =

No. Use the release zip generated by `composer build:zip`; otherwise the Composer vendor dependencies required by the WeChat Pay SDK may be missing.
