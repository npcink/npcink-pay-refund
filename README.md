# Npcink Pay Refund

A WordPress admin console for looking up existing Alipay and WeChat Pay orders by merchant order number and issuing full refunds. It does not create payments or update third-party order status.

## Install

- **Stable: 1.3.10.** Install from the [WordPress.org plugin directory](https://wordpress.org/plugins/npcink-pay-refund/) or use the ZIP attached to the [GitHub release](https://github.com/npcink/npcink-pay-refund/releases/tag/v1.3.10). See the [release record](docs/RELEASE-1.3.10.zh-CN.md) for the scope of merchant verification.
- **Preview: 1.3.11.** The [GitHub pre-release](https://github.com/npcink/npcink-pay-refund/releases/tag/v1.3.11) is for acceptance testing only. Desktop Excel and merchant verification for both payment channels are still pending for that ZIP. See the [pre-release record](docs/RELEASE-1.3.11.zh-CN.md).

Requires WordPress 6.0 or later and PHP 8.1 or later. Use the attached plugin ZIP, not GitHub's autogenerated source archive, which may lack the required Composer dependencies. After activation, open **Plugins > Refund Configuration** to configure the plugin and **Dashboard > Order Refund** to operate it.

## Develop

Run `composer install` to install dependencies, then `composer test` for local PHP regression checks. See the [Chinese project guide](docs/README.zh-CN.md#开发与验证) for other commands and the [development and release standards](docs/DEVELOPMENT-AND-RELEASE-STANDARDS.zh-CN.md) for the full verification and release gates.

Both `composer verify:local` and `composer verify` build a ZIP and can overwrite a same-version ZIP in the checkout. Run them in a separate checkout if the current one holds a frozen candidate.
